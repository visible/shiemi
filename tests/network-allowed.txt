# Hosts the browser is allowed to contact on its own, with no user action.
#
#   python3 utils/audit_network.py --headless --baseline
#
# Anything contacted but not listed here fails the audit. The list starts
# empty on purpose: an idle browser on a cold profile should reach nothing at
# all, so every entry is a concession and needs a reason beside it saying why
# it cannot be removed. Deleting a line is the goal; adding one needs an
# argument.
#
# One host per line. A bare domain also covers its subdomains.

# The component update check, from components/update_client. This is the one
# concession, and it is a real trade: the components left registered are
# revoked-certificate lists, the Certificate Transparency log list, the
# dangerous-download classifier and the captive-portal detector, and a stale
# copy of any of them is a security hole rather than a stale feature. Refusing
# the check means shipping revocation data that never updates.
#
# What it costs is an IP address and the installed component versions, on the
# five-hourly check timer, to a Google host. Self-hosting an update endpoint
# would remove that and is the way to delete this line; until then it stays.
#
# Verified with utils/audit_components.py that nothing else is registered, so
# this check speaks for security components only.
update.googleapis.com

# Filter lists for the bundled content blocker, below. This is the cost of
# shipping one, and it is the largest entry in this file, so the argument
# matters.
#
# A blocker whose lists never update stops working within weeks, quietly,
# while still showing a badge count. So this traffic is not optional the way
# the check above nearly is. What each request is: a plain GET of a text file
# over HTTPS, no cookies, no identity, and nothing about what was browsed.
# They go to the list publishers, never to us, and they stop entirely if the
# user removes the blocker, which they can.
#
# The set is not ours to choose and not fixed by our pin. The blocker fetches
# its own manifest of mirrors at runtime, from the first host below, so which
# mirror serves a given list can change without anything here changing. A new
# uBlock Origin mirror turning up in an audit is that, not a leak: check it
# resolves to the project, add it, move on. Anything else appearing is worth
# treating as a real finding.
#
# The blocker's own lists, served from three interchangeable mirrors.
ublockorigin.pages.dev
ublockorigin.github.io
cdn.jsdelivr.net

# Two lists the blocker enables by default that are not its own. Peter Lowe's
# ad and tracking server list, and the URLhaus malware domain list, which its
# publisher mirrors across all three of these and rotates between them: three
# consecutive audits picked a different one each time.
pgl.yoyo.org
curbengh.github.io
malware-filter.pages.dev
malware-filter.gitlab.io

# The Public Suffix List, which the blocker needs to tell a site apart from a
# third party. "co.uk" is not a registrable domain and no algorithm can know
# that, so the list is the only way, and being wrong about it means filtering
# the wrong requests.
publicsuffix.org
